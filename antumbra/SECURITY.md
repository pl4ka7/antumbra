# Security policy

## Reporting a vulnerability

Please report security issues privately, not in public issues. Use GitHub's
"Report a vulnerability" button on this repository, or email CONTACT_EMAIL.

Include the app version (Settings › About), the device and Android version, and the steps
to reproduce. Leaks of traffic outside Tor, DNS leaks, and ways to identify a user across
sites are treated as critical.

You will get an answer within seven days.

## Supported versions

Only the latest release on Google Play receives fixes. The browser engine (GeckoView) and
tor are updated with every release.
